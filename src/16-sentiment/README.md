# Case Study: Sentiment Analysis using Deep Learning

This case study applies the NLP preprocessing skills from module 15 and the deep learning architectures from module 14 to a practical sentiment classification problem. You will work through the full pipeline — from raw text and problem framing to a trained and evaluated deep learning model — treating sentiment analysis as a production ML task rather than a classroom exercise.

This lesson encourages experimentation. Use the included [*Colaboratory notebook*](https://colab.research.google.com/github/gabrielsanchez/curriculum-ds/blob/main/notebooks/16-sentiment/01_sentiment-case-study_starter.ipynb) to run the code as you learn, or read the lesson and then freely experiment with the notebook's code.

Sentiment analysis is one of the most widely deployed NLP applications in industry: product review analysis, social media monitoring, and customer support triage all rely on some form of it. This case study makes that concrete.

## Lessons

1. **Problem Definition & Data Collection** — Framing the sentiment classification task, understanding the dataset structure, class balance, and establishing a baseline.
2. **NLP Preprocessing & EDA** — Text cleaning, tokenization, vocabulary analysis, sequence length distributions, and preparing data for a deep learning pipeline.
3. **Model Building & Evaluation** — Training and comparing deep learning models for text classification; interpreting accuracy, loss curves, and classification reports.
4. **Module Assessment** — A hands-on assessment extending the sentiment analysis pipeline to a new evaluation task.
