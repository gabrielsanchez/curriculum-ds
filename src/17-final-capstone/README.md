# Final Capstone

The final capstone is your opportunity to demonstrate the full range of skills developed throughout this course. You select a dataset and a question, and you execute the complete data science workflow independently — from initial exploration through a polished, documented analysis with trained models and a written conclusion.

Unlike the Capstone I regression project in module 12, the final capstone is open to any problem type: classification, regression, NLP, or a combination. The deliverable is a professional-quality Jupyter notebook on GitHub that tells a coherent analytical story from start to finish.

## Lessons

1. **End-to-End Project** — Guidance for scoping a project, selecting and justifying a dataset, executing the full ML workflow, and communicating results clearly in a final notebook.
